# Doc Triage CLI

Консольный инструмент для классификации клиентских обращений с помощью **Anthropic Claude API**. Читает `.txt` и `.csv`, извлекает категорию, тему, срочность и ключевые сущности, затем создаёт общий отчёт CSV или Excel. Примеры содержат только вымышленные данные.

## Установка

Требуется Python 3.11+.

```bash
pip install -r requirements.txt
cp .env.example .env
```

В `.env` укажите собственный `ANTHROPIC_API_KEY`. Не добавляйте `.env` в Git. Модель можно изменить через `ANTHROPIC_MODEL`; по умолчанию используется `claude-sonnet-4-5`.

## Использование

```bash
python -m doc_triage process ./examples/input --output report.xlsx
python -m doc_triage process ./examples/input --output report.csv --categories categories.json
```

Формат входных данных:

- `.txt`: весь текст файла — одно обращение;
- `.csv`: обязателен столбец `text`, необязателен `id`. Каждая непустая строка — отдельное обращение.

Категории редактируются в `categories.json` — непустой JSON-массив уникальных строк. Можно передать альтернативный конфиг с помощью `--categories`.

Выходные столбцы: источник, категория, тема, срочность (`high`/`medium`/`low`), сущности, исходный текст и ошибка. Строки сортируются по заданному в конфиге порядку категорий и срочности. Если запрос не удалось обработать, он остаётся в отчёте с описанием ошибки; утилита завершится с кодом 1. При ошибках подключения или ограничениях API применяется повтор запроса с экспоненциальной задержкой.

Пример структуры:

```text
doc-triage-cli/
├── categories.json
├── doc_triage/
│   ├── cli.py       # argparse, прогресс и обработка ошибок
│   ├── input.py     # чтение TXT/CSV
│   ├── triage.py    # Anthropic API и валидация ответа
│   └── report.py    # сортировка, CSV и Excel
├── examples/input/
└── tests/
```

API вызывается через принудительный структурированный `tool_use`: модель должна выбрать ровно одну из ваших категорий. Текст обращения считается данными, а не инструкцией. Ячейки, похожие на формулы, экранируются перед экспортом в таблицу.

Чтобы адаптировать инструмент для своего кейса, поменяйте категории и примеры входных обращений. Не отправляйте в сторонний API персональные или конфиденциальные данные без разрешения их владельцев.

## Локальная проверка без API-ключа

```bash
python -m unittest discover -s tests -v
```
